# References — index

This folder is the grounding material for `skills/skill-builder/` (and every skill it goes
on to produce). Before writing a LordGen skill that touches offers, pricing, outreach, brand
voice, or which platform does what, read the relevant file below instead of guessing or
re-deriving it from memory.

This is reference knowledge, not operating rules — it describes what LordGen **is**, not
day-to-day execution mechanics. It's sourced from `LordGen_Master_Brief_v3.md`
(`Downloads/Lordgen Markdown files/`), the reconciled brief that supersedes the earlier draft.

| File | Read when a skill touches... | Source |
|---|---|---|
| [`architecture.md`](architecture.md) | System structure, the three business loops, which layer owns what | Brief §1, §2, §7 |
| [`platform-map.md`](platform-map.md) | A specific connected tool (HubSpot, Apollo, Vercel, etc.) | Brief §6 |
| [`offers.md`](offers.md) | Proposal drafting, pricing, scoping a client engagement | Brief §3.1 |
| [`human-in-the-loop.md`](human-in-the-loop.md) | Outreach, publishing, pricing changes, anything client-facing or irreversible | Brief §13 |
| [`brand.md`](brand.md) | Visual identity, voice, anything client- or public-facing | `Newsletter Demo/newsletter-brand-guideline.md` |
